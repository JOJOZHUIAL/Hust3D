# 服务器更新指南（Cloudflare 隧道部署）

适用场景：服务器上跑着旧版本，通过 cloudflared 隧道映射到域名，需要更新到最新版。
**Cloudflare 隧道本身不需要任何改动**——它始终指向本机 `127.0.0.1:5000`，只更新代码和依赖。

---

## 一、更新前：三项必查（错过任何一项都会出问题）

| 项目 | 说明 | 后果 |
|---|---|---|
| **备份 `.env`** | 里面是本机数据库密码、管理员清单 | 丢失后连不上数据库 |
| **备份 `uploads\`** | 用户上传的 STL / 签名 / 聊天文件 | 丢失后所有文件 404 |
| **`.env` 要有 `SUPER_ADMIN_STUDENT_IDS`** | 新版超级管理员角色靠它指定 | 没有则没人能管理管理员 |

`.env` 推荐配置：

```
# 管理员学号（逗号分隔）
ADMIN_STUDENT_IDS=2504060306,2401040215,2501010602,2503010828
# 【本次新增】超级管理员学号：可添加/移除管理员，通常只填你自己
SUPER_ADMIN_STUDENT_IDS=2504060306
```

> 说明： 里的学号是「管理员」； 里的学号是「超级管理员」
> （超级管理员同时拥有全部管理员权限，外加网页上的「管理员管理」功能）。
> 别人要加管理员**不用改这个文件**，超管在网页「管理后台 → 管理员管理」里搜学号点一下即可。

改完 `.env` **必须重启后端**才生效（只在启动时读取），角色在**登录时**赋予，
所以改完要**重新登录一次**。

## 二、更新步骤（固定流程，不要单换文件）

历史上踩过的坑：只替换 `app.py` 或只替换部分文件，导致"新页面 + 旧后端/旧数据模型"，
表现为页面反复弹"网络异常"、耗材页白屏等。**必须整目录覆盖。**

1. **开发机生成更新包**
   ```
   python package_update.py
   ```
   得到 `update_pack_日期.zip`（含后端全部代码 + 前端 dist 构建产物 + 部署文档；
   不含 `.env`/`uploads`/虚拟环境/证书，覆盖不会破坏服务器本地数据）。

2. **停服务器后端**：关掉后端窗口；保险起见任务管理器结束所有 `python.exe`。

3. **整目录覆盖**：把 zip 解压出的 `hust3d` 目录覆盖到服务器项目位置
   （已有文件全部替换），然后把备份的 `.env` 和 `uploads\` 放回原位。

4. **补装依赖**（版本有新增时）
   ```
   cd /d D:\hust3d\backend
   .venv\Scripts\python.exe -m pip install -r requirements-win.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

5. **启动**：双击 `启动服务器.bat`（只启动后端 5000，就是隧道指向的端口）。
   新版启动时会**自动补建缺失的数据表**，老数据不受影响。

## 三、更新后验证（顺序照做）

1. `http://127.0.0.1:5000/api/health` → `{"code":0,"msg":"ok"}`
2. `http://127.0.0.1:5000/api/health/db` → `missing_tables` 必须是 **`[]`**
   （不是空数组说明代码没覆盖全或数据库连不上）
3. `http://127.0.0.1:5000/api/consumable/list` → 必须是 `{"code":401,"msg":"未登录"}`
   （返回 404 说明跑的还是旧代码进程，回到第 2 步重来）
4. 浏览器打开域名 **Ctrl+F5 强刷**，检查：登录页新样式 → 底部有「消息」tab
   → 管理后台是五宫格（超管）或四宫格
5. 用超管学号登录，确认「管理员管理」卡片存在

## 四、前端缓存说明（为什么有时"看起来没更新"）

- 带版本哈希的 js/css 已设置**一年强缓存**，页面二次打开秒开；
- `index.html` 不缓存，所以**发新版后强刷一次即可拿到新版本**；
- 用户没强刷会看到旧页面并使用旧路由组件 —— 遇到"页面白屏/样式诡异"先让用户 Ctrl+F5。

## 五、手机 App（APK）

- APK 在开发机用 `frontend\build_apk.bat` 生成，发给用户安装；
- App 内「服务器」栏填 **`http://服务器IP:5000`**（注意是 http 配 5000；
  用域名则填 `https://你的域名`，Cloudflare 自带 HTTPS，摄像头扫码直接可用）；
- 装了新版后端**不需要**重装 App；只有前端界面/功能变化时才需要重发 APK。

## 六、常见问题速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面弹"网络异常" | 后端旧进程 / 数据库连不上 | 查 `health/db` 与后端窗口报错 |
| 耗材页空白 | 前端构建被旧缓存引用 | Ctrl+F5；确认 dist 已覆盖 |
| `missing_tables` 非空 | 代码没覆盖全 | 重新整目录覆盖并重启 |
| App 报"网络异常" | 服务器地址协议/端口写错 | http 配 5000、https 配 5443 |
| 隧道 502 | 后端没在跑 | 双击 `启动服务器.bat` |
| 管理员入口没出现 | `.env` 没配 / 没重新登录 | 配置 `ADMIN_STUDENT_IDS`、`SUPER_ADMIN_STUDENT_IDS` 后重启并重新登录 |
